Wish You The Best - เว็บไซต์พอร์ตโฟลิโอ
==========================================

ในโฟลเดอร์นี้มีเว็บไซต์ครบทั้งหมด
- index.html  = หน้าเว็บ
- bts/        = ภาพเบื้องหลัง
- photos/     = ภาพผลงานและภาพพื้นหลัง
ห้ามแยกไฟล์ออกจากกัน ต้องเก็บไว้ในโฟลเดอร์เดียวกันแบบนี้

เปิดดูในเครื่อง
- ดับเบิลคลิก index.html ได้เลย (ต้องต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์)

เอาขึ้นเว็บฟรี (แนะนำ Netlify)
1. เข้า https://app.netlify.com/drop
2. ลากโฟลเดอร์ wish-you-the-best ทั้งโฟลเดอร์ไปวาง
3. จะได้ลิงก์เว็บทันที สมัครบัญชีเพื่อเก็บเว็บไว้ถาวรและเปลี่ยนชื่อลิงก์ได้

ทางเลือกอื่นที่ฟรีเหมือนกัน: Cloudflare Pages, GitHub Pages, Vercel
ถ้าอยากใช้ชื่อโดเมนของตัวเอง (เช่น wishyouthebest.com) ซื้อโดเมนแล้วเชื่อมใน Netlify ได้
